OS와 앱 버전이 올라가면서 달라진 부분을 반영해 설정 기준을 다시 점검한 버전입니다.

맥에 이미 깔려 있는 단축어 앱만으로도 하루 20분은 줄일 수 있습니다. 실제로 두 달 이상 매일 돌리고 있는 자동화만 골라 만드는 법을 정리했습니다.

**이 글에서 다루는 내용**

1. 첫 단축어로 "스크린샷 정리" 만들기
2. 빠른 동작으로 등록해 Finder 우클릭에 넣기
3. 폴더 자동화로 트리거 없이 실행하기
4. 업무 모드 전환 자동화 묶기

## 왜 지금 정리해야 할까요

- 별도 유료 앱 없이 macOS 기본 기능만으로 구성되므로 회사 보안 정책에서도 대체로 허용됩니다.
- 단축어는 Finder 우클릭, 메뉴 막대, Spotlight, Siri, 자동화 트리거 어디서든 호출됩니다.
- 아이폰·아이패드와 iCloud로 동기화되어 같은 자동화를 모바일에서도 그대로 씁니다.

## 시작 전 준비물

- macOS Ventura 이상(단축어 앱 기본 탑재)
- 자동화하고 싶은 반복 작업 3개를 적은 메모
- 시스템 설정 → 개인정보 보호 및 보안에서 단축어의 폴더 접근 권한

## 단계별 실행 가이드

### 1단계 — 첫 단축어로 "스크린샷 정리" 만들기

새 단축어에서 `폴더 내용 가져오기` → `이미지 변환(JPEG, 품질 80)` → `파일 저장`을 연결합니다. 데스크톱에 쌓이는 PNG 스크린샷을 지정 폴더로 옮기고 용량을 절반 이하로 줄여줍니다.

> **팁:** `파일 저장` 액션에서 "저장 시 확인"을 끄면 실행이 완전히 무인화됩니다.

### 2단계 — 빠른 동작으로 등록해 Finder 우클릭에 넣기

단축어 세부사항 패널에서 "빠른 동작으로 사용"과 "Finder"를 체크합니다. 이제 파일을 선택하고 우클릭 → 빠른 동작에서 바로 호출할 수 있어, 앱을 열 필요가 없습니다.

> **팁:** 시스템 설정 → 키보드 → 단축키 → 서비스에서 자주 쓰는 빠른 동작에 키 조합을 직접 배정하세요.

### 3단계 — 폴더 자동화로 트리거 없이 실행하기

단축어 앱의 "자동화" 탭에서 `폴더` 트리거를 선택하고 다운로드 폴더를 지정합니다. 새 파일이 들어오면 확장자에 따라 문서·이미지·설치파일 폴더로 분기시키는 `조건문` 액션을 붙이면 다운로드 폴더가 계속 비어 있게 됩니다.

> **팁:** 조건문은 파일 확장자보다 `파일 유형` 항목을 쓰는 편이 예외가 적습니다.

### 4단계 — 업무 모드 전환 자동화 묶기

`집중 모드 설정` + `앱 열기(캘린더, 슬랙)` + `Wi-Fi 켜기` + `타이머 시작`을 한 단축어에 넣고 메뉴 막대에 고정합니다. 매일 아침 클릭 한 번으로 작업 환경이 동일하게 세팅됩니다.

> **팁:** 시간 기반 자동화(`매주 평일 09:00`)로 연결하면 클릭조차 필요 없습니다.

## 맥 자동화 도구 선택 기준

| 도구 | 적합한 작업 | 비용 |
| --- | --- | --- |
| 단축어(Shortcuts) | 파일 처리, 앱 제어, 모바일 연동 | 무료(기본 탑재) |
| Automator | 레거시 워크플로우, 폴더 액션 | 무료(기본 탑재) |
| Keyboard Maestro | 창 배치, 복잡한 조건 매크로 | 약 $36 일회성 |
| Hazel | 규칙 기반 파일 자동 정리 | 약 $42 일회성 |

## 실전 프로 팁

- 단축어 이름 앞에 이모지를 붙이면 Spotlight에서 검색·구분이 빨라집니다.
- `텍스트 가져오기`와 `클립보드에 복사`를 조합하면 자주 쓰는 답변 템플릿을 단축키 하나로 붙여넣을 수 있습니다.
- 자동화가 실패하면 단축어 앱 하단의 실행 기록에서 어느 액션에서 멈췄는지 확인하세요.

## 한 걸음 더 — 자동화가 깨지지 않게 유지하는 법

단축어는 만들 때보다 유지할 때 문제가 생깁니다. 가장 흔한 원인은 경로 변경입니다. 폴더 이름을 바꾸거나 아이클라우드 동기화 위치가 달라지면 조용히 실패하고, 실패 사실을 며칠 뒤에야 알게 됩니다. 이를 막으려면 경로를 직접 지정하는 대신 `폴더 선택` 액션으로 북마크된 폴더를 참조하거나, 단축어 마지막에 `알림 표시` 액션을 붙여 성공 여부를 눈으로 확인하게 만드세요. 알림 한 줄이 디버깅 시간을 크게 줄여 줍니다.

두 번째는 권한 만료입니다. macOS 업데이트 후 전체 디스크 접근이나 자동화 권한이 초기화되는 경우가 있습니다. 업데이트 직후에는 자주 쓰는 자동화 두세 개를 수동으로 한 번씩 실행해 권한 대화상자가 뜨는지 확인하는 습관을 들이면 좋습니다. 또한 중요한 자동화는 단축어 앱에서 파일로 내보내 백업해 두세요. 기기를 교체하거나 초기화할 때 iCloud 동기화만 믿었다가 복구하지 못하는 사례가 생각보다 많습니다.

자동화 개수가 늘면 이름 규칙이 중요해집니다. `[정리]`, `[회의]`, `[개발]`처럼 접두어를 붙여두면 Spotlight에서 접두어만 입력해도 관련 자동화가 모입니다. 또한 3개월에 한 번 목록을 열어 실제로 실행된 적 없는 자동화를 지우세요. 쓰지 않는 자동화가 쌓이면 목록에서 원하는 것을 찾는 시간이 늘어 결국 자동화 자체를 덜 쓰게 됩니다. 유지 비용을 낮게 관리하는 것이 장기적으로 가장 중요합니다.

## 자주 겪는 문제와 해결법

### Q. 폴더 자동화가 실행되지 않습니다.

**A.** 해당 폴더에 대한 전체 디스크 접근 권한이 없는 경우가 대부분입니다. 시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근에서 단축어를 추가하고 로그아웃 후 다시 로그인하세요.

### Q. 아이폰에서 같은 단축어가 오류를 냅니다.

**A.** Finder·AppleScript처럼 맥 전용 액션이 포함된 경우입니다. 기기 공용으로 쓸 자동화는 파일 시스템 액션 대신 iCloud Drive 액션으로 대체하세요.

### Q. 회사 맥에서 스크립트 실행이 차단됩니다.

**A.** `셸 스크립트 실행` 액션은 MDM 정책에서 흔히 막힙니다. 대신 기본 제공 액션 조합만으로 구성하면 대부분 정책 안에서 동작합니다.
