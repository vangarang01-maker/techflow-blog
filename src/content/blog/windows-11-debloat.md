노트북을 새로 받거나 윈도우를 초기화하면 항상 같은 순서로 손을 봅니다. 이번에는 각 단계마다 부팅 시간과 유휴 메모리를 측정해서, 실제로 효과가 있는 항목만 남겼습니다.

측정 환경은 Ryzen 7 / 16GB / NVMe SSD 노트북이고, 부팅 시간은 이벤트 뷰어의 `Diagnostics-Performance` 로그 기준입니다.

## 효과가 컸던 항목

### 1. 시작 프로그램 정리 (부팅 -14초)

`Ctrl+Shift+Esc` → 시작 프로그램 앱 탭. 제조사 업데이트 도구, 클라우드 동기화, 게임 런처를 껐습니다. **단일 항목으로는 이게 압도적입니다.**

### 2. 빠른 시작 끄기 (부팅 +2초, 그러나 권장)

역설적으로 부팅은 느려집니다. 하지만 빠른 시작은 커널 상태를 저장하는 방식이라, 드라이버 문제나 원인 불명의 잔버그가 재부팅으로 해결되지 않는 상황을 만듭니다. 2초를 내주고 문제 진단 가능성을 얻는 쪽을 택했습니다.

### 3. 저장 공간 센서 켜기 (유지관리)

설정 → 시스템 → 저장 공간 → 저장 공간 센서. 임시 파일과 다운로드 폴더를 30일 주기로 정리하도록 설정합니다. 반년 뒤 수십 GB 차이가 납니다.

### 4. 백그라운드 앱 권한 정리 (유휴 메모리 -1.1GB)

설정 → 앱 → 설치된 앱 → 각 앱의 고급 옵션 → 백그라운드 앱 권한을 `전원 최적화` 또는 `안 함`으로. 특히 기본 탑재 앱들이 범인입니다.

## 효과가 미미했던 항목

정직하게 적자면, 인터넷에 흔한 아래 항목들은 측정값에 유의미한 변화를 주지 않았습니다.

- 시각 효과 전부 끄기 → 부팅 -0.4초, 대신 화면이 눈에 띄게 투박해짐
- 페이지 파일 수동 설정 → 차이 없음. 16GB 이상이면 자동으로 두세요.
- 서비스 대량 비활성화 → 부팅 -1초 미만, 대신 나중에 원인 못 찾는 오류 유발

## 반드시 해야 하는 보안·개인정보 항목

성능과 무관하지만 초기 세팅에서 빠뜨리면 안 되는 항목입니다.

1. **BitLocker 복구 키 백업** — Microsoft 계정에 저장되었는지 직접 확인하세요. 메인보드 교체 시 이 키가 없으면 데이터를 되살릴 수 없습니다.
2. **진단 데이터 → 필수 항목만**
3. **광고 ID 끄기** — 설정 → 개인 정보 및 보안 → 일반
4. **Windows 업데이트 → 다른 Microsoft 제품 업데이트 켜기**

## 최종 결과

- 부팅 시간: 42초 → 19초
- 유휴 메모리: 4.8GB → 3.2GB
- 소요 시간: 약 25분

목록의 앞 네 개만 해도 효과의 90%를 가져갑니다. 나머지는 취향 영역입니다.
