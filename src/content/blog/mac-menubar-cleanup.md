맥북 프로 14인치를 쓰면서 가장 먼저 무너지는 곳이 메뉴 막대입니다. 앱을 하나 설치할 때마다 아이콘이 하나씩 늘고, 노치가 있는 모델에서는 아이콘이 노치 뒤로 숨어 아예 클릭할 수 없게 됩니다. 6개월 동안 정리 방식을 세 번 바꿔가며 테스트한 결과를 정리했습니다.

## 정리 전에 먼저 측정하기

무작정 지우기 전에 지금 무엇이 떠 있는지 세어보는 편이 낫습니다. 터미널에서 아래 명령으로 로그인 항목을 먼저 확인했습니다.

```bash
# 현재 로그인 시 자동 실행되는 항목 확인
osascript -e 'tell application "System Events" to get the name of every login item'
```

제 경우 18개가 나왔고, 그중 실제로 일주일에 한 번이라도 클릭한 항목은 4개뿐이었습니다. 나머지 14개는 "설치할 때 기본값이 켜져 있어서" 남아 있던 것들입니다.

## 1단계: 시스템 설정에서 끌 수 있는 것부터

macOS 자체 아이콘은 대부분 설정에서 숨길 수 있습니다.

- **제어 센터** → 블루투스, 에어드롭, 화면 미러링은 `필요할 때만 메뉴 막대에 표시`로 변경
- **Wi-Fi**는 남겨두는 편이 낫습니다. 네트워크 문제 진단 시 가장 자주 쓰는 항목입니다.
- **Time Machine**은 숨겨도 백업은 정상 동작합니다. 알림으로 충분합니다.
- **배터리**는 `백분율 표시`만 켜고 아이콘은 유지했습니다.

이 단계만으로 18개 중 6개가 사라졌습니다. 추가 비용은 0원입니다.

## 2단계: 앱 자체 설정 뒤지기

많은 앱이 "메뉴 막대 아이콘 숨기기" 옵션을 환경설정 깊은 곳에 두고 있습니다. Dropbox, Slack, Zoom, 그래머리 계열은 모두 이 옵션이 있습니다. 다만 숨기면 앱을 다시 열 방법이 Spotlight밖에 없으므로, **Spotlight로 이름을 정확히 기억하는 앱만** 숨기는 편이 안전합니다.

> 실수담: Zoom 아이콘을 숨겼다가 회의 5분 전에 화면 공유 설정을 못 찾아 허둥댄 적이 있습니다. 회의용 앱은 남겨두세요.

## 3단계: 유료 앱이 필요해지는 지점

여기까지 하면 보통 6~8개가 남습니다. 이 이하로 줄이려면 Bartender나 Ice 같은 관리 앱이 필요합니다. 6개월 써본 기준을 정리하면 이렇습니다.

| 상황 | 추천 | 이유 |
| :--- | :--- | :--- |
| 아이콘 8개 이하 | 불필요 | 기본 기능으로 충분 |
| 노치 뒤로 아이콘이 숨음 | 필요 | 물리적으로 클릭 불가 |
| 외부 모니터를 자주 바꿈 | 필요 | 해상도별 배치 저장 |

무료 대안인 Ice는 기본적인 숨김/펼침은 충분히 해냅니다. 다만 macOS 대규모 업데이트 직후에는 동작이 불안정했던 경험이 있어, 업데이트 직후 1~2주는 기다렸다가 올리는 쪽을 권합니다.

## 6개월 뒤 결과

현재 상시 노출은 Wi-Fi, 배터리, 시계, 제어 센터, 클립보드 매니저 5개입니다. 나머지는 접힌 영역에 있고, 실제로 펼치는 횟수는 하루 2~3회 정도입니다. 체감상 가장 큰 변화는 아이콘 개수가 아니라 **화면 상단을 습관적으로 훑어보는 횟수가 줄었다는 점**이었습니다.

## 정리

1. 먼저 무엇이 떠 있는지 세어본다.
2. 시스템 설정 → 앱 설정 순서로 무료 정리를 끝낸다.
3. 그래도 8개를 넘으면 그때 관리 앱을 검토한다.

순서를 지키면 대부분은 3단계까지 가지 않고 끝납니다.
