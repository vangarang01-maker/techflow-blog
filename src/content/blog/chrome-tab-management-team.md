개인 세팅을 팀 단위로 확장할 때는 합의와 문서화가 추가로 필요합니다. 도입 과정에서 실제로 걸린 지점 위주로 다시 정리했습니다.

탭이 100개가 되는 이유는 정리 의지가 부족해서가 아니라, **닫아도 다시 찾을 수 있다는 확신이 없어서**입니다. 그 확신을 만드는 4단계 세팅을 정리했습니다.

**이 글에서 다루는 내용**

1. 열린 탭을 통째로 세션에 백업하기
2. 탭 그룹을 작업 맥락 단위로 만들기
3. 읽기 목록과 북마크의 역할 분리하기
4. 메모리 세이버로 비활성 탭 잠재우기

## 왜 지금 정리해야 할까요

- 탭 40개를 넘어가면 제목이 보이지 않아 탐색이 오히려 검색보다 느려집니다.
- 메모리 점유가 커지면 브라우저 전체 응답이 느려지고 노트북 배터리 소모가 늘어납니다.
- "나중에 볼 것"과 "지금 작업 중"이 섞이면 작업 전환 비용이 계속 발생합니다.

## 시작 전 준비물

- 크롬 최신 버전(탭 그룹·메모리 세이버 지원)
- 현재 열린 탭을 한 번 저장해 둘 세션 관리 확장 하나
- 작업 맥락 3~5개를 적은 목록(예: 기획, 개발, 리서치)

## 단계별 실행 가이드

### 1단계 — 열린 탭을 통째로 세션에 백업하기

정리 전에 현재 상태를 잃을까 봐 손을 못 대는 경우가 많습니다. Session Buddy 같은 확장으로 전체 창을 한 번 저장해 두면 심리적 안전장치가 생겨 이후 정리가 훨씬 과감해집니다.

> **팁:** 저장 이름에 날짜를 넣어두면 나중에 복원 지점을 고르기 쉽습니다.

### 2단계 — 탭 그룹을 작업 맥락 단위로 만들기

탭 우클릭 → 새 그룹에 추가로 색과 이름을 지정합니다. 그룹 이름은 프로젝트명이 아니라 "이번 주 처리할 일" 같은 시간 단위가 유지에 유리합니다. 그룹을 접어두면 탭 바가 즉시 정리됩니다.

> **팁:** 그룹은 4개 이하로 유지하세요. 그 이상은 접어도 탐색 비용이 남습니다.

### 3단계 — 읽기 목록과 북마크의 역할 분리하기

한 번 읽고 끝날 자료는 읽기 목록, 반복 접근하는 도구는 북마크 바에 둡니다. 이 구분만 정하면 "일단 열어두기"의 70% 정도가 사라집니다.

> **팁:** 북마크 바 항목은 이름을 3글자 이내로 줄이면 한 줄에 두 배 더 들어갑니다.

### 4단계 — 메모리 세이버로 비활성 탭 잠재우기

설정 → 성능에서 메모리 세이버를 켜고, 항상 활성 상태로 둘 사이트(작업 도구, 모니터링 대시보드)만 예외로 등록합니다. 비활성 탭은 메모리에서 내려가지만 클릭하면 즉시 복구됩니다.

> **팁:** 화상회의·실시간 편집 도구는 반드시 예외 목록에 넣으세요. 잠들면 연결이 끊깁니다.

## 탭 정리 방식 비교

| 방식 | 장점 | 한계 |
| --- | --- | --- |
| 탭 그룹 | 맥락 유지, 접기로 즉시 정리 | 창을 닫으면 관리 부담 |
| 읽기 목록 | 가볍고 동기화됨 | 분류·검색 기능이 약함 |
| 세션 저장 확장 | 전체 상태 복원 가능 | 확장 권한이 광범위함 |
| 북마크 폴더 | 영구 보관에 적합 | 쌓이기만 하고 안 봄 |

## 실전 프로 팁

- `Ctrl/Cmd + Shift + T`는 최근 닫은 탭을 되살립니다. 이 단축키를 익히면 탭을 닫는 심리적 저항이 줄어듭니다.
- 매주 금요일 퇴근 전 모든 창을 세션에 저장하고 전부 닫는 규칙을 만들면 월요일 시작이 가벼워집니다.
- 검색으로 3초 안에 다시 찾을 수 있는 페이지는 그냥 닫는 것이 기준선입니다.

## 한 걸음 더 — 브라우저 프로필로 맥락 자체를 분리하기

탭 정리가 반복해서 무너진다면 프로필 분리를 검토할 차례입니다. 업무용과 개인용 프로필을 나누면 로그인 계정, 확장, 북마크, 방문 기록이 전부 분리되어 탭이 섞이지 않습니다. 업무 프로필에는 업무 도구만 두고 개인 프로필에는 쇼핑·SNS를 두면, 업무 중에 개인 탭이 눈에 들어오는 상황 자체가 사라집니다. 프로필 전환은 창 단위로 이뤄지므로 작업 전환 신호로도 작동합니다.

프로젝트 단위로 프로필을 만드는 것도 방법입니다. 다만 프로필이 5개를 넘어가면 어느 창이 어느 프로필인지 헷갈리므로, 각 프로필에 다른 테마 색을 지정해 시각적으로 구분하세요. 여기에 프로필별로 시작 페이지를 다르게 설정하면 창을 여는 순간 필요한 도구가 열립니다. 프로필 분리는 탭 개수를 직접 줄이지는 않지만, 한 창에서 감당해야 하는 맥락의 수를 줄여 체감 부담을 크게 낮춥니다.

마지막으로 확장 권한을 점검하세요. 탭 관리 확장은 대부분 "모든 사이트의 데이터 읽기 및 변경" 권한을 요구합니다. 이는 로그인 세션과 입력 내용까지 접근할 수 있다는 뜻이므로, 사용자 수가 적거나 개발자가 불분명한 확장은 피하는 것이 좋습니다. 꼭 필요하다면 권한을 "클릭할 때만"으로 제한하고, 금융이나 사내 시스템을 쓰는 프로필에서는 아예 비활성화하세요.

## 자주 겪는 문제와 해결법

### Q. 탭을 닫으면 다시 못 찾을까 봐 불안합니다.

**A.** 방문 기록 검색(`Ctrl/Cmd + H`)이 생각보다 강력합니다. 최근 일주일 안에 본 페이지는 키워드 한두 개로 대부분 복구되므로, 닫기 전 기억할 단어 하나만 정해두면 충분합니다.

### Q. 탭 그룹이 창을 닫으면 사라집니다.

**A.** 크롬 최신 버전에서는 그룹을 저장할 수 있습니다. 그룹 이름 우클릭 → "그룹 저장"을 켜면 북마크 바에 남아 다음에 클릭 한 번으로 전체 복원됩니다.

### Q. 확장 프로그램이 많아 브라우저가 느립니다.

**A.** `chrome://extensions`에서 최근 30일간 쓰지 않은 확장을 끄세요. 특히 콘텐츠 스크립트를 모든 페이지에 주입하는 확장이 체감 속도를 크게 떨어뜨립니다.
