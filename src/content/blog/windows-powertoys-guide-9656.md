PowerToys는 마이크로소프트가 직접 배포하는 무료 유틸리티 묶음입니다. 20개가 넘는 모듈 중 실제로 매일 손이 가는 7개만 골라 설정 기준을 정리했습니다.

**이 글에서 다루는 내용**

1. winget으로 설치하고 자동 시작 켜기
2. FancyZones로 화면 분할 레이아웃 고정하기
3. PowerToys Run을 기본 런처로 삼기
4. 텍스트 추출과 이미지 리사이저 붙이기

## 왜 지금 정리해야 할까요

- 마이크로소프트 공식 배포라 사내 보안 심사 통과가 상대적으로 수월합니다.
- 창 배치·런처·이미지 리사이즈처럼 윈도우에 없던 기능을 별도 유료 앱 없이 채웁니다.
- 모듈별로 켜고 끌 수 있어 필요 없는 기능이 메모리를 먹지 않습니다.

## 시작 전 준비물

- Windows 11 또는 Windows 10 21H2 이상
- winget 또는 Microsoft Store 설치 권한
- 현재 쓰는 창 배치 습관 메모(모니터 개수 포함)

## 단계별 실행 가이드

### 1단계 — winget으로 설치하고 자동 시작 켜기

터미널에서 `winget install Microsoft.PowerToys`를 실행합니다. 설치 후 일반 설정에서 "관리자 권한으로 실행"과 "시스템 시작 시 실행"을 켜야 관리자 창에서도 단축키가 동작합니다.

> **팁:** 업데이트 알림을 켜두면 모듈 버그 수정이 빠르게 반영됩니다.

### 2단계 — FancyZones로 화면 분할 레이아웃 고정하기

`Win + Shift + \`로 편집기를 열고 3열 레이아웃을 만듭니다. 좌측은 브라우저, 중앙은 에디터, 우측은 메신저 식으로 폭을 다르게 잡으면 울트라와이드에서 특히 효율이 큽니다. Shift를 누른 채 창을 드래그하면 영역에 흡착됩니다.

> **팁:** "창을 마지막 영역으로 복원"을 켜면 노트북을 도킹할 때마다 배치가 자동 복구됩니다.

### 3단계 — PowerToys Run을 기본 런처로 삼기

`Alt + Space`로 열리는 런처에서 앱 실행뿐 아니라 계산(`=32*1.1`), 단위 변환, 폴더 열기, 프로세스 종료(`kill`)까지 처리합니다. 인덱싱 대상에서 불필요한 플러그인을 끄면 응답이 눈에 띄게 빨라집니다.

> **팁:** 검색어 앞에 `>` 를 붙이면 셸 명령, `?`를 붙이면 파일 검색으로 범위가 좁혀집니다.

### 4단계 — 텍스트 추출과 이미지 리사이저 붙이기

`Win + Shift + T`로 화면 어디서든 이미지 속 글자를 복사할 수 있습니다. 캡처된 문서나 화면 공유 중 코드도 그대로 텍스트가 됩니다. 이미지 리사이저는 파일 우클릭에서 여러 장을 한 번에 줄여줍니다.

> **팁:** 한글 인식률을 올리려면 설정 → 텍스트 추출에서 언어를 한국어로 지정하세요.

## PowerToys 모듈 우선순위

| 모듈 | 해결하는 문제 | 추천도 |
| --- | --- | --- |
| FancyZones | 창 배치가 매번 흐트러짐 | ★★★★★ |
| PowerToys Run | 앱·파일 검색이 느림 | ★★★★★ |
| 텍스트 추출 | 이미지 속 글자 재입력 | ★★★★☆ |
| Keyboard Manager | 키 배열 커스터마이즈 | ★★★☆☆ |

## 실전 프로 팁

- Keyboard Manager로 Caps Lock을 Ctrl로 바꾸면 단축키 입력 피로가 크게 줄어듭니다.
- Awake 모듈은 발표·빌드 중 절전 진입만 임시로 막아줘 전원 설정을 건드릴 필요가 없습니다.
- 모듈을 전부 켜지 말고 3개로 시작해 2주마다 하나씩 늘리세요. 단축키 충돌을 추적하기 쉬워집니다.

## 한 걸음 더 — 여러 대의 PC에서 같은 환경 유지하기

PowerToys는 설정을 파일로 내보낼 수 있습니다. 사무실 PC와 집 PC를 함께 쓴다면 `%LOCALAPPDATA%\Microsoft\PowerToys` 아래 설정 폴더를 클라우드 폴더에 백업해 두고, 새 기기에서 그대로 복원하면 FancyZones 레이아웃과 단축키가 한 번에 맞춰집니다. 특히 모니터 구성이 같은 두 기기라면 레이아웃 재설정 시간이 통째로 사라집니다.

모니터 구성이 다른 경우에는 FancyZones의 "모니터별 레이아웃 저장" 옵션을 켜 두는 것이 좋습니다. 노트북 단독 화면, 사무실 듀얼 모니터, 집 울트라와이드처럼 세 가지 구성을 각각 저장해 두면 도킹할 때마다 해당 구성이 자동으로 적용됩니다. 여기에 "가상 데스크톱별 레이아웃"까지 나누면 작업 성격에 따라 화면 구성을 통째로 전환할 수 있어, 창을 하나씩 옮기는 시간이 거의 사라집니다.

업데이트 정책도 정해두는 편이 좋습니다. PowerToys는 개발 속도가 빨라 새 모듈과 변경이 자주 들어오는데, 자동 업데이트를 켜두면 익숙해진 단축키가 바뀌는 경우가 있습니다. 업무에 중요한 모듈을 쓰고 있다면 릴리스 노트를 확인한 뒤 수동으로 올리는 방식이 안전합니다. 반대로 크게 의존하지 않는다면 자동 업데이트로 두고 버그 수정을 빨리 받는 편이 낫습니다.

## 자주 겪는 문제와 해결법

### Q. 단축키가 다른 앱과 충돌합니다.

**A.** 각 모듈 설정에서 활성화 키를 직접 바꿀 수 있습니다. 충돌이 잦다면 `Win + Alt` 조합을 기본 규칙으로 정하고 모듈 전체를 그 규칙에 맞추세요.

### Q. FancyZones가 특정 앱에서만 동작하지 않습니다.

**A.** 전체 화면 모드이거나 자체 창 관리를 하는 앱(일부 게임, 가상머신)입니다. 설정의 앱 제외 목록에 추가해 두면 불필요한 흡착 시도를 막을 수 있습니다.

### Q. 메모리 사용량이 부담됩니다.

**A.** 쓰지 않는 모듈을 끄면 상주 메모리가 절반 이하로 떨어집니다. 특히 파일 탐색기 미리보기와 비디오 회의 음소거 모듈이 상대적으로 무겁습니다.
