매일 수시간씩 켜두는 이 앱, 하지만 90%의 사용자가 이 치명적인 기능의 존재조차 모르고 있습니다. 

윈도우(Windows)라는 운영체제 이야기입니다. 우리는 매일 출근해서 퇴근할 때까지 윈도우 환경에서 수많은 창을 띄우고, 텍스트를 복사하고, 파일 탐색기를 뒤집니다. 하지만 정작 마이크로소프트(MS)가 공식 배포하는 비기의 생산성 도구 모음인 ‘**PowerToys(파워토이즈)**’의 존재를 아는 실무자는 의외로 드뭅니다. 알고 있더라도 "어려워 보인다"는 이유로 설치를 미루곤 하죠.

테크플로우(TechFlow) 수석 에디터로서 단언하건대, PowerToys에서 제공하는 20여 가지 모듈 중 딱 7가지 실전 기능만 제대로 세팅해 두면 하루 최소 30분 이상의 무의미한 조작 시간을 줄일 수 있습니다. 유료 툴을 전혀 쓸 필요 없이, 오직 MS 공식 도구만으로 윈도우 작업 환경을 Mac 부럽지 않게 끌어올리는 심층 세팅 가이드를 공개합니다.

## 왜 굳이 PowerToys인가? 사내 도입과 효율성의 3가지 이유

기업 환경에서 새로운 생산성 소프트웨어를 도입할 때 가장 큰 걸림돌은 단연 '보안 심사'와 '비용'입니다. PowerToys가 실무진과 IT 관리자 모두에게 환영받는 이유는 명확합니다.

1. **검증된 보안성**: 마이크로소프트가 오픈소스로 직접 관리하고 배포하므로, 까다로운 사내 보안 가이드라인을 상대적으로 수월하게 통과합니다.
2. **유료 유틸리티 대체**: macOS의 Magnet(창 분할), Alfred/Raycast(런처), 별도 OCR 프로그램 등 유료 앱이 제공하던 핵심 기능을 단 하나의 무료 팩으로 통합합니다.
3. **가벼운 자원 관리**: 20개가 넘는 모듈 중 내가 필요한 모듈만 개별적으로 켜고 끌(On/Off) 수 있어 백그라운드 메모리 점유율을 최적화할 수 있습니다.

## 실전 세팅 전 사전 준비사항

세팅을 시작하기 전 아래 3가지 항목이 준비되어 있는지 확인하세요.

* **운영체제**: Windows 11 전체 버전 또는 Windows 10 버전 21H2 이상
* **설치 권한**: Terminal(winget) 실행 또는 Microsoft Store 앱 설치 권한
* **현재 화면 습관 체크**: 사용하는 모니터 개수(단일, 듀얼, 울트라와이드)와 주요 작업 창 개수

## 생산성을 즉시 올려주는 PowerToys 핵심 7가지 실전 설정

### 1. winget 설치 및 권한 최적화
가장 빠르고 깔끔한 설치 방법은 윈도우 터미널을 이용하는 것입니다. `Win + X` 키를 누른 뒤 [터미널] 또는 [PowerShell]을 열고 아래 명령어를 입력하세요.

```bash
winget install Microsoft.PowerToys
```

설치가 완료되면 PowerToys를 실행한 뒤 **[일반]** 탭으로 이동합니다. 여기서 반드시 켜야 할 설정 두 가지가 있습니다.

* **관리자 권한으로 실행**: 켬 (관리자 권한으로 열린 프로그램 위에 창을 배치하거나 단축키를 적용하려면 필수입니다.)
* **시스템 시작 시 실행**: 켬

> 💡 **팁**: [일반] 탭 하단의 '업데이트 알림'을 켜두면, 윈도우 빌드 업데이트 시 발생할 수 있는 모듈 꼬임 현상이 빠르게 버그 수정 버전으로 자동 해결됩니다.

---

### 2. FancyZones: 화면 분할의 완벽한 통제 (울트라와이드 필수)
기존 윈도우의 `Win + 화살표` 분할 방식은 모니터가 크거나 3개 이상의 창을 띄울 때 한계가 명확합니다. FancyZones는 화면에 사용자 지정 '구역(Zone)'을 그려두고 창을 흡착시키는 모듈입니다.

1. `Win + Shift + \` 키를 눌러 FancyZones 편집기를 열어줍니다.
2. [새 레이아웃 만들기]를 누르고 **[열]** 모드를 선택합니다.
3. 3열 구조를 만들되, 중앙 에디터 영역(50%), 좌측 브라우저(30%), 우측 메신저/참고문서(20%) 비율로 폭을 지정합니다.
4. 설정에서 “**Shift 키를 누른 상태에서 드래그하여 영역 활성화**”를 켭니다.

이제 어떤 창이든 `Shift`를 누른 채 드래그하면 미리 설정한 영역으로 자석처럼 찰싹 붙습니다. 창 크기를 마우스로 조정하느라 허비하던 수십 초의 시간이 0.5초로 줄어듭니다.

> 💡 **팁**: FancyZones 설정 내 “**창을 마지막 영역으로 복원**” 옵션을 켜두면, 노트북을 외부 미팅 후 사무실 모니터에 다시 도킹할 때 기존 창 배치가 100% 자동 복구됩니다.

---

### 3. PowerToys Run: 손가락이 키보드를 떠나지 않는 검색 런처
`Alt + Space`를 누르면 화면 중앙에 미니멀한 검색창이 등장합니다. 윈도우 기본 시작 메뉴 검색보다 3배 이상 빠르고 정확합니다.

* **단순 앱 실행**: "chrome", "excel" 입력 후 엔터
* **즉석 계산기**: `=125000*1.1` 입력 시 결과값 바로 출력 (`Enter` 누르면 결과 복사)
* **프로세스 강제 종료**: `kill chrome` 입력 시 실행 중인 크롬 프로세스 즉시 종료
* **단위 변환**: `100usd to krw` 또는 `50inch to cm` 즉시 환산

반응 속도를 극대화하려면 PowerToys Run 설정의 **[플러그인]** 메뉴에서 쓰지 않는 항목(예: OneNote 검색, Time and Date 등)을 끄세요. 입력 후 결과가 뜨는 반응 시간이 50ms 미만으로 지연 없이 쾌적해집니다.

> 💡 **팁**: 검색어 맨 앞에 `>`를 붙이면 윈도우 셸(CMD/PowerShell) 명령어로 동작하고, `?`를 붙이면 파일 및 폴더 전용 검색 모드로 전환됩니다.

---

### 4. 텍스트 추출 (Text Extractor): 이미지 속 글자를 1초 만에 복사
보안 정책상 텍스트 복사가 막힌 캡처 이미지, PDF 문서, 웹 세미나 화면 속 코드를 일일이 타이핑하고 계셨나요? 

`Win + Shift + T` 키를 누른 뒤 화면에서 텍스트가 있는 영역을 드래그하세요. 즉시 OCR(광학 문자 인식)이 작동하여 해당 글자가 클립보드에 텍스트 형태로 저장됩니다.

* **필수 설정 경로**: `PowerToys 설정` → `텍스트 추출` → `기본 언어`를 ‘**한국어**’로 지정해야 한글 인식률이 99%까지 끌어올려집니다.

---

### 5. 이미지 리사이저 (Image Resizer): 우클릭 한 번으로 대량 용량 줄이기
블로그 포스팅, 사내 보고서 작성 시 고용량 이미지 수십 장의 크기를 줄여야 할 때 웹사이트 업로드나 포토샵 실행 없이 해결할 수 있습니다.

1. 이미지 파일들을 다중 선택한 뒤 마우스 우클릭을 합니다.
2. 메뉴에서 **[이미지 크기 조정]**을 클릭합니다.
3. 미리 설정된 크기(대형 1920px, 중형 1366px 등)를 선택하고 [크기 조정]을 누르면 완료됩니다.

10MB짜리 원본 사진 20장을 단 3초 만에 300KB 수준의 웹 최적화 이미지로 변환할 수 있습니다.

---

### 6. Keyboard Manager: 핑거 피로도를 줄이는 키 재배치
자주 쓰지 않는 키를 생산적인 단축키로 리매핑합니다. 가장 추천하는 세팅은 사용률이 낮은 **`Caps Lock` 키를 `Ctrl` 키로 변경**하는 것입니다. 

단축키 입력 시 약지를 멀리 뻗지 않아도 되므로 손목 부담이 50% 이상 감소합니다. 또한 특정 프로그램에서 자주 쓰이는 복잡한 3조합 단축키를 단일 키나 2조합 키로 바꿀 수도 있습니다.

---

### 7. Awake: 전원 옵션을 건드리지 않는 절전 모드 방지
대용량 파일 다운로드, 서버 빌드 작업, 장시간 발표 중 화면이 꺼지거나 컴퓨터가 절전 모드로 들어가는 것을 막기 위해 윈도우 전원 설정을 매번 바꾸는 것은 매우 번거롭습니다.

작업 표시줄 트레이 아이콘에서 컵 모양의 **Awake** 아이콘을 우클릭하고 “**계속 켜두기**” 또는 “**2시간 동안 켜두기**”를 선택하세요. 전원 세팅을 건드리지 않고도 원하는 시간 동안만 깔끔하게 절전 진입을 차단합니다.

## 실전 테크 에디터의 골든 룰 3가지

> 💡 **팁 1: 한 번에 전부 켜지 마세요**
> 설치 직후 20여 개 모듈을 모두 활성화하면 기존 윈도우 단축키와 충돌이 발생하거나 익숙해지기 전에 피로감이 찾아옵니다. 첫 주에는 **FancyZones**와 **PowerToys Run** 두 가지만 켜고 몸에 익히세요. 2주 간격으로 하나씩 모듈을 추가하는 것이 정착률이 가장 높습니다.
>
> 💡 **팁 2: 단축키 통일성 유지하기**
> 조합 키가 헷갈린다면 `Win + Alt + [알파벳]` 형태로 자신만의 시그니처 단축키 규칙을 만드세요.
>
> 💡 **팁 3: 서식 없는 텍스트 붙여넣기 기능 활용**
> 최신 PowerToys 버전에 추가된 `Win + Ctrl + Alt + V` (Paste as Plain Text) 모듈을 켜두면, 웹페이지의 지저분한 폰트 색상과 배경 스타일을 지우고 깔끔한 순수 텍스트만 문서에 붙여넣을 수 있습니다.

## 한 걸음 더 — 여러 대의 PC에서 동일한 작업 환경 유지하기

사무실 데스크톱과 이동용 노트북, 혹은 집 PC까지 여러 기기를 혼용한다면 기기마다 PowerToys 설정을 새로 하는 것은 소모적입니다.

PowerToys는 설정 백업 및 복원 기능을 완벽히 지원합니다.

1. 메인 PC의 PowerToys 설정 메뉴 하단 **[백업 및 복원]**으로 이동합니다.
2. **[백업]** 버튼을 눌러 설정 파일(.ptb)을 추출한 뒤 OneDrive나 Google Drive 같은 클라우드에 저장합니다.
3. 새 기기에 PowerToys를 설치하고 해당 파일로 **[복원]**을 누르면 FancyZones 레이아웃, 키 매핑, Run 런처 설정이 즉시 100% 동일하게 복구됩니다.

만약 사무실에서는 듀얼 모니터를 쓰고 외부에서는 노트북 단독 화면을 쓴다면, FancyZones의 “**모니터별 레이아웃 저장**” 옵션을 켜 두세요. 모니터 연결 해제 시 노트북용 1열 레이아웃으로 전환되고, 사무실 디스플레이가 연결되면 즉시 3열 레이아웃으로 자동 복원되어 설정에 손댈 필요가 완전히 사라집니다.

## 자주 묻는 질문 (FAQ)

### Q1. 단축키가 기존 윈도우 기능이나 다른 프로그램(예: Photoshop)과 충돌합니다.
**A.** PowerToys 설정의 각 모듈 페이지 최상단에서 단축키 변경(`연필 아이콘`)이 가능합니다. 충돌이 발생하면 `Win + Ctrl + [키]` 혹은 `Alt + Shift + [키]` 조합처럼 일반 프로그램에서 잘 쓰지 않는 조합으로 재지정해 주세요.

### Q2. FancyZones가 캡처 도구나 특정 가상머신(VM) 창에서 동작하지 않습니다.
**A.** 해당 앱이 '관리자 권한'으로 실행 중이거나 자체 창 프레임을 사용하는 앱일 가능성이 높습니다. PowerToys 일반 설정에서 “**관리자 권한으로 실행**”이 켜져 있는지 확인하세요. 만약 게임이나 특정 독점 앱이라면 FancyZones 설정 내 '제외된 응용 프로그램' 항목에 해당 executable(.exe) 이름을 등록하여 흡착 시도를 깔끔하게 차단할 수 있습니다.

### Q3. 백그라운드 메모리(RAM) 점유율이 걱정됩니다.
**A.** 쓰지 않는 모듈의 스위치를 끄면 해당 프로세스가 메모리에서 완전히 해제됩니다. 특히 **파일 탐색기 추가 기능(미리보기 판넬)**과 **비디오 회의 음소거** 모듈은 상주 메모리를 상대적으로 많이 소비하므로, 사용하지 않는다면 반드시 꺼두는 것을 권장합니다. 기본 7개 핵심 기능만 켜둘 경우 전체 RAM 점유율은 100MB 미만으로 매우 가볍습니다.

## 마치며

PowerToys 도입 시 가장 흔히 범하는 실수는 "일단 유용해 보이니 전부 켜고 보자"는 접근입니다. 기능이 너무 많으면 단축키를 외우다 지쳐 결국 앱을 삭제하게 됩니다.

오늘 당장 **FancyZones**로 나만의 화면 분할 레이아웃을 만들고, **PowerToys Run**(`Alt + Space`)으로 앱을 켜는 습관 두 가지만 2주 동안 유지해 보세요. 손가락의 동선이 줄어들고 작업 흐름이 끊기지 않는 쾌적함을 체감하는 순간, 윈도우를 바라보는 여러분의 시선은 완전히 달라져 있을 것입니다.
