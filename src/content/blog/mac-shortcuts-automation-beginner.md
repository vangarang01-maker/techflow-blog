맥북으로 업무를 하다 보면 매일 똑같이 반복하는 손작업들이 있습니다. 바탕화면에 널브러진 스크린샷 정리, 이미지 확장자 변환, 다운로드 폴더 정돈, 출근 직후 슬랙과 캘린더를 켜는 일까지. 저 역시 이 반복 작업을 없애보겠다고 인터넷 블로그 튜토리얼 10여 개를 똑같이 따라 하며 파이썬 스크립트를 짜고 셸 스크립트를 등록하느라 주말 사흘을 통째로 날린 적이 있습니다. 권한 에러(`Operation not permitted`)가 터지거나 OS가 업데이트될 때마다 구동이 멈춰 수많은 에러 메시지와 싸워야 했죠.

온갖 시행착오와 삽질 끝에 건진 결론은 의외로 간단했습니다. 외부 유료 앱이나 복잡한 스크립트 작성 없이, **macOS 기본 탑재 앱인 '단축어(Shortcuts)'의 권한 세팅 단 한 줄**만 제대로 잡으면 production 환경에서도 절대로 튕기지 않는 무중단 자동화 시스템을 완성할 수 있다는 사실이었습니다. 오늘 포스팅에서는 실제 제 맥북에서 두 달 이상 단 한 번의 오류 없이 매일 구동 중인 실전 단축어 세팅과 구축 가이드를 차근차근 정리해 드립니다.

## 왜 지금 '맥 단축어'를 시작해야 할까?

3rd Party 자동화 프로그램은 훌륭하지만 몇 가지 장벽이 있습니다. 보조 프로그램을 설치해야 하고, 사내 보안 정책에 걸리거나, 연간 구독료를 내야 하는 부담이 있죠. 반면 맥 단축어는 다음과 같은 확실한 강점이 있습니다.

1. **사내 보안 정책 통과**: macOS 시스템 기본 내장 기능이므로 별도 소프트웨어 승인 절차 없이 기업용 맥북에서도 바로 활용 가능합니다.
2. **다양한 호출 경로**: Finder 우클릭 마우스 메뉴, 상단 메뉴 막대, Spotlight(`Cmd + Space`), Siri, 또는 바탕화면 아이콘까지 유연하게 호출할 수 있습니다.
3. **iCloud 생태계 연동**: 맥에서 만든 단축어는 추가 작업 없이 아이폰, 아이패드와 자동 동기화되어 모바일에서도 동일하게 실행됩니다.

## 사전 준비물 및 기본 권한 세팅

자동화를 구성하기 전, 맥 환경을 올바르게 세팅해 두어야 중간에 권한 창이 뜨며 흐름이 끊기지 않습니다.

* **권장 OS**: macOS Ventura (13.0) 이상
* **사전 준비**: 하루에 3번 이상 반복하는 노가다 작업 3가지 메모하기
* **필수 권한 설정**:
  `시스템 설정` → `개인정보 보호 및 보안` → `전체 디스크 접근` 항목으로 이동합니다. 단축어 앱을 찾아 스위치를 ‘**켜짐**’으로 변경하세요. 이 세팅이 되어 있어야 다운로드 폴더나 데스크톱 파일에 제약 없이 접근할 수 있습니다.

## 실전! 업무 시간을 줄여주는 단축어 단계별 제작 가이드

### 1. 스크린샷 용량 축소 및 자동 정돈

데스크톱에 쌓이는 PNG 형태의 스크린샷은 파일 하나당 3～8MB에 달해 용량을 크게 차지합니다. 이를 JPEG 품질 80%로 압축하면 용량이 **최대 70% 이상 줄어들며**, 지정된 폴더로 자동 이동됩니다.

1. 단축어 앱을 열고 우측 상단 `+` 버튼을 눌러 새 단축어를 만듭니다.
2. 우측 검색창에서 `폴더 내용 가져오기`를 검색해 드래그합니다. 폴더 위치를 `데스크톱`으로 지정합니다.
3. `이미지 변환` 액션을 이어 붙이고 포맷을 `JPEG`, 품질을 `80%`로 설정합니다.
4. `파일 저장` 액션을 붙여 저장 위치를 `문서 > 스크린샷_모음` 폴더로 지정합니다.

> 💡 **팁**: `파일 저장` 액션 하단의 상세 화살표를 눌러 **'저장 시 확인' 옵션을 끄면** 팝업 창 없이 무인으로 깔끔하게 처리됩니다.

### 2. Finder 우클릭 '빠른 동작' 등록하기

생성한 단축어를 굳이 단축어 앱을 열지 않고, Finder에서 마우스 우클릭으로 바로 실행하도록 설정해 보겠습니다.

1. 작성 중인 단축어 우측 상단 '세부사항(i)' 아이콘을 클릭합니다.
2. ‘**빠른 동작으로 사용**’과 ‘**Finder**’ 항목에 체크합니다.
3. 이제 Finder에서 파일을 선택하고 `우클릭` → `빠른 동작` 메뉴를 보면 해당 단축어가 즉시 호출됩니다.

> 💡 **팁**: `시스템 설정` → `키보드` → `키보드 단축키` → `서비스`로 이동하면 내가 만든 빠른 동작에 `Option + Cmd + S` 같은 글로벌 단축키를 직접 할당할 수 있습니다.

### 3. 다운로드 폴더 자동 청소 (폴더 트리거)

다운로드 폴더에 파일이 들어올 때마다 조건에 맞춰 자동 분기 처리하는 무인 세팅입니다.

1. 단축어 앱 좌측 탭에서 `자동화`를 선택하고 `+` 버튼을 누릅니다.
2. 트리거 종류 중 `폴더`를 선택하고 대상 폴더를 `다운로드`로 지정합니다.
3. `조건문(만약 ~이라면)` 액션을 추가하여 파일의 속성을 분류합니다.
4. 예를 들어 `파일 유형`이 `PDF` 또는 `문서`이면 `문서` 폴더로 이동시키고, `ZIP` 또는 `DMG`면 `임시` 폴더로 이동하게 설정합니다.

> 💡 **팁**: 조건문 분기 시 확장자 문자열 비교보다 **`파일 유형`** 속성을 이용하는 편이 시스템 예외 처리에 훨씬 안정적입니다.

### 4. 출근 직후 업무 모드 원클릭 셋업

매일 아침 출근해서 캘린더, 슬랙, 노션을 일일이 켜고 집중 모드를 설정하는 과정을 단 1초 만에 해결합니다.

1. 액션 순서: `집중 모드 설정(업무 - 켜짐)` → `앱 열기(Slack)` → `앱 열기(노션)` → `앱 열기(캘린더)` → `Wi-Fi 켜기`
2. 작성 완료 후 우측 상단 세부사항에서 ‘**메뉴 막대에 고정**’을 활성화합니다.
3. 맥 상단 메뉴 막대에 아이콘이 생성되어, 클릭 한 번으로 모든 출근 세팅이 끝납니다.

> 💡 **팁**: `자동화` 탭에서 `시간 기반 트리거`를 선택하고 `매주 평일 08:55`로 설정해 두면 클릭조차 할 필요 없이 출근 시간에 맞춰 작업 환경이 세팅됩니다.

## 생산성을 극대화하는 실전 오퍼레이션 팁

* **Spotlight 검색 속도 개선**: 단축어 이름 제일 앞에 `[정리]`, `[업무]` 같은 접두어나 이모지(📁, 🚀)를 붙여두세요. `Cmd + Space`로 Spotlight를 열었을 때 검색 결과 상단에 즉시 노출되어 실행이 압도적으로 빨라집니다.
* **상주 텍스트 템플릿**: `텍스트` 액션에 자주 쓰는 회의록 양식이나 이메일 거절 답장 템플릿을 넣어두고, 바로 뒤에 `클립보드에 복사` 액션을 붙여두세요. 단축키 한 번에 템플릿이 클립보드에 들어가 붙여넣기(`Cmd + V`)만 하면 됩니다.
* **실행 오류 디버깅**: 자동화가 원인 없이 멈춘다면 단축어 앱 하단 실행 기록 로그를 확인하세요. 어느 액션 단계에서 권한 문제나 경로 오류가 발생했는지 초 단위로 파악할 수 있습니다.

## 한 걸음 더 — 자동화가 깨지지 않게 유지하는 법

자동화 시스템은 잘 만드는 것보다 ‘**깨지지 않게 유지하는 것**’이 더 중요합니다. 실무에서 자동화가 멈추는 가장 흔한 원인은 **경로 변경**입니다. 사용자가 폴더 이름을 바꾸거나 iCloud Drive 동기화 경로가 바뀌면 단축어는 에러 없이 조용히 실패합니다. 이를 방지하려면 하드코딩된 절대 경로 대신 `폴더 선택` 액션을 활용해 북마크된 폴더 상수를 참조하게 만들거나, 단축어 맨 마지막 단계에 `알림 표시` 액션을 넣어 정상 처리 결과를 사용자가 눈으로 확인할 수 있게 구성하세요.

두 번째는 **macOS 대규모 업데이트 후 권한 초기화**입니다. OS 버전이 올라가면 기존 부여했던 '전체 디스크 접근'이나 'Finder 제어 권한'이 오프 상태로 풀리는 경우가 빈번합니다. 업데이트를 마친 직후에는 핵심 단축어 2～3개를 수동으로 실행해 권한 대화상자가 정상적으로 뜨는지 점검해야 합니다. 또한, 중요한 단축어는 파일 형식(`.shortcut`)으로 내보내기(Export)하여 별도 백업 폴더에 보관해 두는 것이 안전합니다.

마지막으로 **주기적인 단축어 다이어트**가 필요합니다. 3개월에 한 번씩 단축어 목록을 열어 실제로 지난달에 단 한 번도 실행하지 않은 자동화는 과감히 삭제하거나 비활성화하세요. 쓰지 않는 자동화가 쌓이면 전체 목록의 가독성이 떨어지고 관리가 복잡해집니다. 가벼운 상태를 유지하는 것이 장기적인 생산성 향상의 핵심입니다.

## 자주 묻는 질문 (FAQ)

### Q1. 폴더 자동화를 설정했는데 파일이 들어와도 동작하지 않습니다.
> **A.** macOS 보안 TCC(Transparent, Consent, and Control) 정책 때문입니다. `시스템 설정` → `개인정보 보호 및 보안` → `전체 디스크 접근`에서 단축어 앱을 삭제 후 재등록하거나, 권한을 껐다 켠 뒤 **맥을 로그아웃 후 다시 로그인**해 보세요. 대부분의 경로 접근 이슈가 해결됩니다.

### Q2. 맥에서 잘 돌아가는 단축어가 아이폰으로 동기화된 후 에러가 납니다.
> **A.** Finder 제어, AppleScript 실행, 맥 전용 로컬 경로 지정 등 **macOS 전용 액션**이 포함되어 있기 때문입니다. 아이폰과 공용으로 사용할 단축어라면 로컬 경로 대신 `iCloud Drive` 전용 액션과 앱 제어 액션 위주로 재구성해야 합니다.

### Q3. 회사 맥북인데 스크립트 실행이나 셸 명령어가 막혀 있습니다.
> **A.** 사내 MDM(기기 관리 솔루션) 정책으로 인해 `셸 스크립트 실행`이나 `AppleScript` 액션이 차단된 상태입니다. 스크립트 액션을 사용하지 않고 단축어 앱이 자체 제공하는 **기본 블록 액션(파일 이동, 이미지 변환, 텍스트 대치 등)**만으로 조합하면 보안 정책을 건드리지 않고 정상 구동됩니다.
