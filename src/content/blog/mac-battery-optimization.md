배터리 성능은 사용량보다 **충전 습관과 상시 실행 앱**이 좌우합니다. 설정 몇 개와 습관 두 가지로 체감 사용 시간이 달라집니다.

**이 글에서 다루는 내용**

1. 전력 소모 상위 앱부터 찾기
2. 최적화된 충전과 상한 설정 켜기
3. 디스플레이와 백그라운드 설정 손보기
4. 열 관리와 보관 습관 잡기

## 왜 지금 정리해야 할까요

- 리튬 배터리는 완전 충·방전 구간에서 열화가 가장 빠릅니다.
- 백그라운드 상주 앱 한두 개가 전력의 절반을 쓰는 경우가 흔합니다.
- 배터리 교체 비용이 적지 않아 관리 효과가 곧 비용 절감입니다.

## 시작 전 준비물

- 시스템 설정 → 배터리 화면
- 활성 상태 보기(활성 화면 → 에너지 탭)
- 현재 사이클 수 확인(시스템 정보 → 전원)

## 단계별 실행 가이드

### 1단계 — 전력 소모 상위 앱부터 찾기

활성 상태 보기의 에너지 탭에서 12시간 평균 에너지 소비가 큰 앱을 확인합니다. 브라우저 탭, 동기화 클라이언트, 화상회의 앱이 대개 상위에 옵니다.

> **팁:** 상위 3개만 정리해도 사용 시간이 눈에 띄게 늘어납니다.

### 2단계 — 최적화된 충전과 상한 설정 켜기

설정 → 배터리 → 배터리 상태에서 최적화된 충전을 켭니다. 데스크톱처럼 상시 전원 연결로 쓴다면 80% 상한 옵션을 사용하는 편이 장기 수명에 유리합니다.

> **팁:** 외출 전날에는 상한을 잠시 해제해 100%로 충전하세요.

### 3단계 — 디스플레이와 백그라운드 설정 손보기

밝기는 자동으로 두되 최대치 사용을 줄이고, 사용하지 않는 앱의 백그라운드 새로 고침과 위치 서비스를 끕니다. 프로모션 디스플레이는 주사율 자동 전환을 유지하세요.

> **팁:** 키보드 백라이트는 생각보다 소모가 큽니다. 밝은 곳에서는 꺼두세요.

### 4단계 — 열 관리와 보관 습관 잡기

이불·쿠션 위 사용은 배기를 막아 발열과 열화를 동시에 키웁니다. 장기간 보관할 때는 50% 충전 상태로 서늘한 곳에 두는 것이 권장 기준입니다.

> **팁:** 완전 방전 후 장기 보관은 배터리를 영구 손상시킬 수 있습니다.

## 배터리 소모 요인과 대응

| 요인 | 영향 | 대응 |
| --- | --- | --- |
| 상시 실행 앱 | 매우 큼 | 자동 실행 목록 정리 |
| 화면 밝기 | 큼 | 자동 밝기 + 상한 조절 |
| 고온 환경 | 수명 열화 | 통풍 확보, 직사광선 회피 |
| 100% 상시 유지 | 열화 가속 | 80% 상한 사용 |

## 실전 프로 팁

- 사이클 수보다 최대 용량(%) 수치를 기준으로 교체 시점을 판단하세요.
- 외장 모니터 연결 시 GPU 사용이 늘어납니다. 이동 중에는 해상도를 낮추는 편이 유리합니다.
- 저전력 모드는 장시간 회의·이동 구간에서만 켜면 체감 성능 손실 없이 이득을 봅니다.

## 한 걸음 더 — 외장 모니터와 도킹 환경에서의 소모

외장 모니터를 연결하면 GPU 사용량이 늘어 배터리 소모가 눈에 띄게 커집니다. 특히 고해상도 모니터나 두 대 이상 연결 시에는 어댑터 자체가 전력을 나눠 쓰기 때문에 충전 속도가 소모를 따라가지 못하는 경우도 있습니다. 도킹 상태에서 배터리가 줄어든다면 충전기 출력(W)이 충분한지부터 확인하세요.

이동이 잦다면 도킹 해제 시 자동으로 저전력 모드로 전환되도록 단축어를 만들어 두는 방법이 있습니다. 전원 어댑터 연결 여부를 조건으로 삼아 저전력 모드와 화면 밝기를 함께 조정하면, 상황에 따라 매번 설정을 바꿀 필요가 없습니다. 작은 자동화지만 하루 종일 이동하며 일하는 날에는 사용 시간 차이가 분명하게 드러납니다.

배터리 상태를 주기적으로 기록해 두면 교체 시점을 판단하기 쉽습니다. 두 달에 한 번 최대 용량 수치와 사이클 수를 메모해 두면 열화 속도가 보입니다. 갑자기 수치가 크게 떨어졌다면 사용 습관이나 환경에 변화가 있었는지 확인할 신호입니다. 고온 환경에서 충전하며 고부하 작업을 하는 패턴이 가장 흔한 원인이며, 이 경우 작업 중에는 충전을 잠시 멈추는 것만으로 개선됩니다.

## 자주 겪는 문제와 해결법

### Q. 충전을 계속 꽂아두면 안 되나요?

**A.** 최신 macOS는 상태를 관리하지만, 100%로 오래 유지될수록 열화가 빨라집니다. 80% 상한 옵션이 있다면 켜두는 편이 낫습니다.

### Q. 배터리가 갑자기 빨리 닳습니다.

**A.** 최근 설치한 앱이나 macOS 업데이트 후 색인 작업이 원인인 경우가 많습니다. 하루 정도 기다린 뒤에도 그렇다면 에너지 탭을 확인하세요.

### Q. 최대 용량이 몇 %면 교체해야 하나요?

**A.** 80% 아래로 떨어지고 실사용에서 불편하다면 교체 시점입니다. 수치만으로 조급하게 판단할 필요는 없습니다.

### Q. 배터리를 아예 빼고 전원으로만 쓸 수는 없나요?

**A.** 최근 맥북은 배터리 분리가 불가능하며, 시스템 전원 관리도 배터리를 전제로 동작합니다. 상시 전원 환경이라면 80% 상한 옵션을 쓰는 것이 사실상 최선의 대안이며, 한 달에 한 번 정도는 배터리로만 사용해 셀 밸런싱이 이뤄지게 하는 편이 좋습니다.
