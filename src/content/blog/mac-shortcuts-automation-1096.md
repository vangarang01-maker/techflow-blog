"매일 오후 6시만 되면 바탕화면이 스크린샷 50장과 다운로드 파일로 뒤덮여요. 매번 일일이 이름 바꾸고 정리하느라 퇴근이 20분씩 늦어지는데, 유료 유틸리티나 파이썬 코딩이라도 배워야 할까요?"

얼마 전 테크플로우 독자 한 분이 보내온 SOS 메일의 내용입니다. 시중에는 월 구독료를 요구하는 파일 정리 프로그램이나 창 관리 툴이 넘쳐나지만, 별도의 프로그램을 설치하거나 복잡한 터미널 명령어를 입력할 필요가 전혀 없습니다. 여러분이 매일 켜는 맥(macOS)에는 이미 최고 수준의 자동화 엔진인 ‘**단축어(Shortcuts)**’ 앱이 무료로 탑재되어 있기 때문입니다.

지금 당장 5분만 투자해 단 3단계로 반복 작업을 털어내 보세요.
1. **단축어 앱 실행**: `Cmd + Space`로 Spotlight를 열고 ‘단축어’를 입력해 엽니다.
2. **블록 조립**: 준비된 레고 블록 형태의 액션 3～4개를 마우스로 드래그해 연결합니다.
3. **트리거 지정**: Finder 우클릭 메뉴(빠른 동작)나 특정 시간에 자동 실행되도록 스위치만 켜면 끝납니다.

실제로 두 달 넘게 실무 현장에서 매일 돌리며 검증한, 하루 20분 이상의 마우스 노가다를 없애주는 맥 단축어 실전 구축법을 가감 없이 공유합니다.

## 1. 왜 서드파티 앱 대신 '단축어'인가?

맥 환경에서 업무를 자동화할 때 단축어가 가장 강력한 무기가 되는 이유는 명확합니다.

- **완벽한 보안성**: 회사 보안 정책(MDM)이 엄격한 환경에서도 macOS 네이티브 시스템 앱이므로 보안 경고나 차단 없이 자유롭게 사용할 수 있습니다.
- **전방위 호출 인터페이스**: 단축어 하나만 짜두면 Finder 우클릭(빠른 동작), 메뉴 막대(Menu Bar), Spotlight, 키보드 단축키, 심지어 Siri 음성 명령까지 원하는 모든 경로에서 0.5초 만에 실행할 수 있습니다.
- **애플 생태계 동기화**: iCloud를 통해 아이폰, 아이패드와 즉시 동기화되므로 모바일과 데스크톱을 오가며 동일한 업무 로직을 연속성 있게 활용할 수 있습니다.

### 사전 준비: 1분 환경 점검
- **운영체제**: macOS Ventura(13.0) 이상 권장
- **권한 설정**: `시스템 설정` → `개인정보 보호 및 보안` → `전체 디스크 접근 권한`에서 '단축어' 앱을 활성화합니다. (파일 일괄 이동 및 이름 변경 시 권한 거부 오류를 방지하기 위한 필수 세팅입니다.)

## 2. 바로 써먹는 실전 단축어 파이프라인 4선

### ① 데스크톱 스크린샷 일괄 압축 및 보관
업무 중 캡처한 PNG 스크린샷은 용량이 장당 4～8MB에 달해 메일 전송 시 용량 초과를 유발하고 바탕화면을 어지럽힙니다.

- **액션 구성**:
  1. `폴더 내용 가져오기`: 데스크톱(바탕화면) 폴더를 타깃으로 지정합니다.
  2. `다음 항목 일치 파일 필터링`: 종류가 '이미지'이고, 생성일이 '오늘'인 파일만 추려냅니다.
  3. `이미지 변환`: 포맷을 JPEG로 변경하고 품질 슬라이더를 80%로 맞춥니다. (가독성 손실 없이 용량이 약 65% 이상 절감됩니다.)
  4. `파일 저장`: `문서/Screenshots_Archive` 폴더로 지정합니다.
  5. `파일 삭제`: 원본 데스크톱 파일을 삭제(휴지통 이동)하도록 연결합니다.

> 💡 **팁**: `파일 저장` 액션의 상세 화살표를 열어 **"저장 시 확인" 토글을 반드시 꺼주세요.** 팝업 창 확인 단계가 생략되어 진정한 원클릭 무인 자동화가 완성됩니다.

### ② Finder 우클릭 '빠른 동작' 등록
매번 단축어 앱을 열 필요 없이, 파일을 선택하고 마우스 우클릭 한 번으로 동작시키는 방법입니다.

1. 단축어 편집기 우측 상단의 **세부사항(아이콘 모양)** 패널을 엽니다.
2. “**빠른 동작으로 사용**”에 체크하고, 입력 수신 대상을 “**Finder**”로 지정합니다.
3. 이제 Finder에서 여러 장의 이미지를 드래그 선택한 뒤 `우클릭` → `빠른 동작` → `[단축어 이름]`만 누르면 3초 만에 리사이징과 포맷 변환이 끝납니다.

> 💡 **팁**: `시스템 설정` → `키보드` → `키보드 단축키` → `서비스`로 이동하면 내가 만든 빠른 동작에 직접 단축키(예: `Cmd + Option + Shift + S`)를 배정해 키보드만으로 실행할 수 있습니다.

### ③ '다운로드' 폴더 무인 자동 분류
다운로드 폴더는 며칠만 방치해도 설치 파일(.dmg, .pkg), 문서(.pdf, .xlsx), 압축 파일(.zip)이 뒤섞여 혼돈의 카오스가 됩니다.

- **액션 구성**:
  1. 단축어 앱 좌측 사이드바의 **자동화** 탭을 클릭하고 새 자동화를 생성합니다.
  2. 트리거를 `폴더`로 잡고 `다운로드` 폴더를 선택합니다.
  3. `조건문(만약 ~라면)` 액션을 삽입합니다:
     - `파일 유형`이 PDF/Word/Excel인 경우 → `문서` 폴더로 이동
     - `파일 확장자`가 dmg/pkg/zip인 경우 → `설치파일_보관` 폴더로 이동
     - `파일 유형`이 이미지인 경우 → `리소스` 폴더로 이동
4. 웹 브라우저에서 파일을 내려받는 순간 백그라운드에서 실시간으로 폴더가 분기되어 다운로드 폴더는 언제나 비어 있는 상태를 유지합니다.

> 💡 **팁**: 조건문을 걸 때 단순 확장자(문자열)보다는 macOS가 자체 식별하는 `파일 유형(Type)` 속성을 사용하는 것이 대소문자 예외나 알 수 없는 확장자 오류를 피하는 가장 확실한 방법입니다.

### ④ 출근 즉시 1초 세팅: 올인원 업무 모드
출근해서 슬랙 켜고, 캘린더 열고, 사내 메신저 띄우고, 방해금지 켜는 과정을 단 한 번의 클릭으로 묶어버립니다.

- **액션 구성**:
  1. `집중 모드 설정`: '업무 집중 모드'를 켬 상태로 전환.
  2. `앱 열기`: Slack, Notion, Google Chrome을 연속으로 배치.
  3. `URL 열기`: 사내 대시보드 및 지라(Jira) 스프린트 보드 링크 연결.
  4. `타이머 시작`: 50분 뽀모도로 타이머 가동.
- 편집기 상단에서 “**메뉴 막대에 고정**”을 켜두면 맥 상단 메뉴바에 아이콘이 상주하게 됩니다.

> 💡 **팁**: 단축어 앱 내 자동화 설정에서 `특정 시간(평일 09:00)`에 실행되도록 스케줄링해 두면 맥북을 열자마자 작업 환경이 스스로 세팅됩니다.

## 4. 생산성을 2배로 올리는 디테일 꿀팁

- **Spotlight 검색 최적화**: 단축어 이름 앞에 `[이미지]`, `[업무]`, `[정리]`와 같은 머리말이나 이모지(📸, 📁)를 붙이세요. `Cmd + Space` 검색창에서 몇 글자만 쳐도 오타 없이 최우선 결과로 호출됩니다.
- **자주 쓰는 상용구 클립보드 주입**: `텍스트 가져오기` 액션에 정형화된 고객 응대 템플릿이나 세금계산서 발행 정보 텍스트를 넣고, `클립보드에 복사` 액션을 붙입니다. 단축키 하나로 서식이 포함된 긴 문장을 즉시 붙여넣을 수 있습니다.
- **실패 지점 역추적**: 자동화가 멈추거나 묵묵부답일 때는 단축어 앱 편집기 하단의 ‘**실행 기록(재생 버튼 옆 아이콘)**’을 누르세요. 어느 블록에서 데이터 누락이나 권한 충돌이 일어났는지 빨간색 표시로 즉시 확인 가능합니다.

## 5. 문제 해결 (FAQ)

### Q. 폴더 자동화가 백그라운드에서 동작하지 않습니다.
**A.** macOS의 강화된 샌드박스 정책 때문입니다. `시스템 설정` → `개인정보 보호 및 보안` → `전체 디스크 접근 권한` 목록에 '단축어'가 켜져 있는지 확인하세요. 만약 이미 켜져 있다면 토글을 껐다 켠 뒤, 맥 계정에서 로그아웃 후 다시 로그인해야 시스템 데몬(shortcutd)이 갱신됩니다.

### Q. 맥에서 잘 되던 단축어가 아이폰에서는 에러를 뿜어냅니다.
**A.** 단축어 내에 `Finder 항목 이동`, `AppleScript 실행` 등 macOS 전용 라이브러리가 포함되어 있기 때문입니다. 모바일과 함께 쓸 워크플로우라면 로컬 파일 경로 대신 `iCloud Drive` 액션을 기반으로 설계해야 iOS 기기에서도 끊김 없이 실행됩니다.

### Q. 사내 보안 규정 때문에 셸 스크립트(Shell Script) 실행이 막힙니다.
**A.** 기업용 보안 솔루션(Jamf, SentinelOne 등)은 `셸 스크립트 실행` 액션을 악성 행위로 탐지하여 프로세스를 강제 종료합니다. 정규식 텍스트 파싱이나 파일 가공은 스크립트 대신 단축어가 기본 제공하는 `일치하는 텍스트 가져오기`, `파일 필터링` 액션 블록으로 대체해 구성하면 사내 검출을 피하고 정상 작동합니다.

## 6. 한 걸음 더 — 자동화가 깨지지 않게 유지하는 법

단축어는 처음 만들 때보다 ‘**유지보수**’ 단계에서 스트레스가 발생합니다. 자동화 시스템이 중단되지 않고 견고하게 유지되도록 관리하는 3가지 실전 팁입니다.

1. **절대 경로 대신 북마크 액션 활용**: 폴더 이름을 수정하거나 외장 드라이브를 교체하면 하드코딩된 파일 경로는 깨져버립니다. 직접 경로를 타이핑하지 말고 액션 내 `폴더 선택` 인터페이스를 통해 시스템 북마크 형태로 경로를 잡으세요. 또한 단축어 마지막 단계에 반드시 `알림 표시` 액션을 넣어 "정리 완료: N개 파일 처리됨" 형태의 피드백을 눈으로 확인하도록 설계해야 오류를 제때 인지할 수 있습니다.
2. **OS 메이저 업데이트 후 권한 검증 및 백업**: macOS 메이저 업데이트(예: Sonoma → Sequoia)가 진행되면 자동화 관련 권한 설정이 간헐적으로 초기화됩니다. 업데이트 직후 핵심 단축어 2～3개를 수동 실행해 시스템 승인 팝업을 먼저 통과시켜 두세요. 더불어 중요한 자동화는 단축어 편집기에서 `파일` → `공유` → `파일로 내보내기(.shortcut)`를 통해 로컬 드라이브에 주기적으로 백업하는 것이 안전합니다.
3. **정기적인 디이어트와 네이밍 룰**: 단축어가 20개를 넘어가면 오히려 관리 피로도가 올라갑니다. 분기별(3개월)로 한 번씩 단축어 목록을 점검하여 한 달 이상 실행하지 않은 자동화는 과감히 삭제하거나 '보관함' 폴더로 격리하세요. 실행하지 않는 단축어는 Spotlight 검색 효율만 떨어뜨립니다.

자동화는 거창한 파이프라인부터 시작하면 십중팔구 중간에 포기하게 됩니다. 오늘 하루 업무를 진행하며 “**아, 이 동작은 방금 전에도 똑같이 했는데?**” 싶은 사소한 마우스 클릭 하나를 찾아 단축어로 옮겨보세요. 그 작은 블록 하나가 쌓여 여러분의 매일 30분을 진짜 가치 있는 업무에 집중할 수 있게 돌려줄 것입니다.
