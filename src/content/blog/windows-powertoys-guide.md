PowerToys는 마이크로소프트가 직접 개발하고 배포하는 무료 오픈소스 유틸리티 묶음입니다. 현재 20개가 넘는 다양한 모듈이 포함되어 있지만, 실제 업무 현장에서 매일 손이 가고 생산성을 체감할 수 있는 기능은 정해져 있습니다. 테크플로우에서 직접 검증한 핵심 기능 7가지와 효율적인 설정 기준을 정리해 드립니다.

## 왜 PowerToys를 사용해야 할까?

윈도우 기본 기능만으로는 다중 모니터 창 관리나 빠른 검색, 이미지 서식 변경 등에서 아쉬움이 생깁니다. 보통 서드파티 유료 앱을 개별 설치해 해결하지만, PowerToys는 다음과 같은 뚜렷한 장점을 제공합니다.

* **사내 보안 심사 통과 수월**: 마이크로소프트 공식 배포 소프트웨어이므로 외부 유틸리티에 엄격한 기업 환경에서도 보안 승인을 받기 상대적으로 용이합니다.
* **단일 앱으로 통합 제공**: 화면 분할, 런처, 이미지 크기 조절, OCR 텍스트 추출 등 별도 프로그램으로 나누어져 있던 기능들을 하나로 해결합니다.
* **불필요한 리소스 차단**: 개별 모듈을 독립적으로 켜고 끌 수 있어, 쓰지 않는 기능이 백그라운드 메모리를 차지하지 않습니다.

### 설치 전 준비 사항
* **OS 버전**: Windows 11 또는 Windows 10 버전 21H2 이상
* **권한**: winget 명령어 실행 또는 Microsoft Store 앱 설치 권한
* **사전 체크**: 현재 주로 사용하는 창 배치 습관과 모니터 개수 파악

## 핵심 기능 설정 및 단계별 활용법

### 1. winget으로 설치하고 자동 시작 설정하기

가장 깔끔한 설치 방법은 윈도우 터미널(PowerShell)을 이용하는 것입니다. 터미널을 열고 아래 명령어를 입력합니다.

```cmd
winget install Microsoft.PowerToys
```

설치가 완료되면 PowerToys를 실행한 뒤 **일반** 설정 메뉴로 이동합니다. 여기서 다음 두 가지 항목을 반드시 활성화해야 합니다.

1. **관리자 권한으로 항상 실행**: 관리자 권한으로 열린 다른 프로그램(터미널, 작업 관리자 등) 위에서도 PowerToys 단축키가 정상 작동합니다.
2. **시스템 시작 시 실행**: PC를 켤 때 백그라운드에서 자동으로 로드됩니다.

> **에디터 팁**: '업데이트 알림'을 켜두면 새로 추가되는 모듈 기능이나 버그 수정 사항을 빠르게 반영할 수 있습니다.

### 2. FancyZones로 화면 분할 레이아웃 고정하기

기본 윈도우 스냅 기능보다 훨씬 강력한 창 분할 기능입니다. 단축키 `Win + Shift + \`를 누르면 편집기가 열립니다.

1. **레이아웃 생성**: '새 레이아웃 만들기'를 누르고 3열(Grid) 구조를 만듭니다.
2. **비율 조절**: 좌측 25%(웹 브라우저), 중앙 50%(코드/문서 에디터), 우측 25%(슬랙/메신저) 형태로 폭을 다르게 잡습니다. 울트라와이드 모니터에서 특히 효율성이 뛰어납니다.
3. **창 흡착**: `Shift` 키를 누른 채 창을 드래그하면 설정한 구역이 강조되며 손쉽게 흡착됩니다.

> **에디터 팁**: FancyZones 설정에서 “**창을 마지막 영역으로 복원**” 옵션을 켜두면, 노트북을 외부 모니터에 도킹할 때마다 창 배치가 이전 상태로 자동 복원됩니다.

### 3. PowerToys Run을 기본 런처로 삼기

`Alt + Space` 단축키로 호출하는 빠른 실행 런처입니다. 맥OS의 Spotlight나 Raycast와 유사한 환경을 제공합니다.

* **수식 계산**: `=32*1.1`을 입력하면 즉시 계산 결과를 출력하고 클립보드에 복사할 수 있습니다.
* **프로세스 종료**: `kill`을 입력하고 프로세스 이름을 검색해 앱을 강제 종료합니다.
* **성능 최적화**: 설정 → PowerToys Run → 플러그인 목록에서 사용하지 않는 검색 플러그인(예: OneNote, Visual Studio Workspace 등)을 비활성화하면 검색 응답 속도가 눈에 띄게 빨라집니다.

> **에디터 팁**: 검색어 앞에 `>`를 붙이면 셸(Shell) 명령어로 실행되며, `?`를 붙이면 파일 검색 모드로 빠르게 전환됩니다.

### 4. 텍스트 추출과 이미지 리사이저 붙이기

이미지 속 글자를 즉시 텍스트로 변환하는 **텍스트 추출(Text Extractor)**은 `Win + Shift + T` 단축키로 동작합니다. 캡처 영역을 지정하면 문서 스캔본이나 영상 속 코드, 이미지 텍스트가 즉시 클립보드에 텍스트로 저장됩니다.

* **한글 인식률 높이기**: PowerToys 설정 → 텍스트 추출 메뉴에서 기본 언어가 **한국어**로 지정되어 있는지 확인하세요. (윈도우 언어 팩 설정 연동)

**이미지 리사이저(Image Resizer)**는 탐색기 context 메뉴에 통합됩니다. 이미지 파일들을 다중 선택한 뒤 마우스 우클릭 → `이미지 크기 수정`을 선택하면, 사전 설정된 해상도(대, 중, 소)로 일괄 변경할 수 있습니다.

## 생산성을 극대화하는 실전 팁

> **Keyboard Manager 활용법**  
> Keyboard Manager를 사용해 자주 쓰지 않는 `Caps Lock` 키를 `Ctrl` 키로 매핑해 보세요. 왼쪽 새끼손가락의 이동 거리가 획기적으로 줄어들어 단축키 입력 시 손목 피로가 크게 감소합니다.

> **Awake 모듈 활용법**  
> 긴 빌드 작업이나 발표 중 PC가 절전 모드로 들어가는 것을 막기 위해 윈도우 전원 설정을 매번 변경할 필요가 없습니다. 트레이 아이콘의 Awake 기능을 켜면 일정 시간 동안 임시로 수면 모드 진입을 차단합니다.

> **단계적 도입 권장**  
> 처음부터 모든 모듈을 켜두면 단축키 충돌이 발생했을 때 원인을 찾기 어렵습니다. 처음에 2～3개 핵심 기능만 켜서 사용하다가, 2주 단위로 모듈을 하나씩 추가하며 익히는 방식을 권장합니다.

## 자주 묻는 질문 (FAQ)

### Q1. 단축키가 다른 프로그램과 충돌합니다.
각 모듈의 상세 설정 페이지로 이동하면 활성화 단축키를 사용자가 원하는 조합으로 변경할 수 있습니다. 충돌을 방지하기 위해 기본 규칙을 `Win + Alt + [특정키]` 조합으로統一하여 설정하는 것을 추천합니다.

### Q2. FancyZones가 특정 앱에서만 동작하지 않습니다.
해당 앱이 전체 화면 모드로 실행 중이거나 자체 창 관리를 수행하는 가상머신, 일부 게임 프로그램일 경우 스냅이 작동하지 않을 수 있습니다. FancyZones 설정의 '앱 제외 목록'에 해당 실행 파일명(.exe)을 등록하면 불필요한 흡착 시도로 인한 렉 현상을 막을 수 있습니다.

### Q3. 메모리 사용량이 부담스럽지 않나요?
사용하지 않는 모듈을 비활성화하면 점유 메모리를 절반 이하로 줄일 수 있습니다. 특히 백그라운드 렌더링을 지속하는 **파일 탐색기 미리보기** 모듈과 **비디오 회의 음소거** 모듈을 끄면 메모리 사용량이 눈에 띄게 절감됩니다.

## 한 걸음 더: 여러 대의 PC에서 동일한 작업 환경 유지하기

PowerToys는 작성한 모든 설정값을 파일 형태로 백업하고 복원하는 기능을 제공합니다. 사무실 PC와 개인 노트북 등 여러 기기를 동시에 사용하는 환경이라면 설정을 일일이 다시 잡을 필요가 없습니다.

`%LOCALAPPDATA%\Microsoft\PowerToys` 경로에 위치한 설정 폴더를 클라우드 드라이브(OneDrive, Google Drive 등)에 백업해 두고, 새 기기에서 해당 경로에 덮어씌우면 FancyZones 레이아웃과 커스텀 단축키가 즉시 적용됩니다. 동일한 해상도의 모니터를 사용하는 환경이라면 레이아웃 재설정 시간을 완벽하게 아낄 수 있습니다.

모니터 환경이 기기마다 다르다면 FancyZones 내부 옵션 중 “**모니터별 레이아웃 저장**”을 켜두는 것이 좋습니다. 노트북 단독 사용 화면, 사무실 듀얼 모니터, 집 울트라와이드 모니터의 세 가지 구성을 각각 저장해 두면 케이블을 연결하는 순간 해당 디스플레이에 맞는 레이아웃이 자동으로 호출됩니다. 추가로 "가상 데스크톱별 레이아웃" 옵션까지 결합하면 작업 공간(개발, 문서 작업, 개인 용도)에 따라 창 분할을 통째로 전환할 수 있습니다.

마지막으로 업데이트 관리 정책을 정해두는 것을 권장합니다. PowerToys는 개발주기가 빨라 신규 기능이 자주 추가되지만, 자동 업데이트 과정에서 기존 설정이나 단축키 매핑이 변경되는 경우가 간혹 발생합니다. 업무용 핵심 기기에서는 릴리스 노트를 확인한 후 수동으로 안정 버전을 올라가는 방식이 바람직하며, 개인 기기에서는 자동 업데이트를 활용해 신규 모듈과 버그 수정 패치를 빠르게 받아보는 것이 유리합니다.
